# C--Porting-and-Optimization
The porting to C# and optimization of technically sound, and future-career, relevant school projects/assignments

07/30/2026
This first port is a Python text-based adventure game. The initial C# version is as close to a line by line
port from Python as I could make it. Further updates will add features, clean up output, and improve overall
structure of the system. 

07/31/26
Implemented Random dice rolls and updated logic for item visibility and win conditions. These dice rolls determine the quality of item the user will see when entering a room
that contains an item. If the roll exceeds the treshold then the user will be able to equip the higher tier item. This
update is in line with the intended updates for the optimization of this application.
